# 空中サインをパンチして発動する

## 操作

- 右トリガーを押して1画を描き、離す。軌跡は空中に残る。
- 次の画も同じ操作で追加する。描き始めの視線を基準に、各画の位置関係を判定する。
- トリガーを離し、拳をサインの範囲外へ引いてから、サイン全体の中央付近を殴る。左右どちらの拳でもよい。
- 発動すると緑に光って砕ける。認識失敗・未割当・クールダウン中は赤く光って消えるので、描き直す。
- 描画中と最後の画を離してから0.25秒間は発動しない。触れるだけでは発動しない。
- 最後の画から20秒放置すると消える。最大4画。5画目は新しいサインとして始める。

## 現在の割り当て（対戦用・テスト用共通）

| サイン | アビリティ |
|---|---|
| △ | 電車 |
| ぺ（1画目に「へ」、2画目に右上の小さい○） | ペンギン |
| □ | 衝撃波 |
| ○だけ、へだけ | 未割当。発動しない |

最初は「へ」を横幅30〜50cm程度、半濁点を直径5〜12cm程度で描く。半濁点は「へ」の頂点から右上付近に置く。

## 確認ポイント

1. △を描いて離すだけでは電車が出ない。線が残る。
2. ゆっくり触れても出ない。拳を引き、速く殴ると1回だけ出る。
3. 「へ」を描いて離し、右上に○を追加してもまだ出ない。殴るとペンギンが出る。
4. ○だけ、半濁点が左・下・大きすぎる場合はペンギンが出ない。
5. 視線を動かして2画目を描いても、最初の画との相対位置で認識する。
6. 連打・クールダウン中に発動演出だけ成功扱いにならない。
7. 2人接続で、自分の描画・パンチからだけ技が発動する。相手の描画中に自分がトリガーを押しても干渉しない。

サイン・軌跡は現段階では本人にだけ表示する。技の発動は既存のAbilityLoadoutのRPC経由。相手にもサインを見せる同期は未実装。

## 開発用チェック

Unityメニュー `Wapawapa > Tests > Check Air Signs` で形状・配置・パンチ通過判定の回帰チェックを実行できる。追加後、編集モードで初回だけ自動実行される。
Consoleの `Air sign regression checks PASSED` が成功。実際のHMDでの認識しやすさ、拳の速度閾値、ネットワーク動作は別途実機で確認する。
